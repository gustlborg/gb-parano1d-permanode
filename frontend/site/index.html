parano1d-permanode

This permanode records the transaction history its Parano1d node prunes and serves it as a JSON API under /api/v1/. No frontend is configured; set site_dir in permanode.toml to serve one.

statsindexer state, chain and network figures
blocks?limit=Nnewest blocks (up to 200)
block/height/{h}block with its transactions
block/hash/{hash}same, by hash
tx/{txid}transaction with inputs, outputs, receipt data and the fee split into miner share and burn
address/{a}?page=&page_size=recorded and live balance, transactions
address/{a}/utxosthe address's live UTXOs from the node
mempoolthe node's pending transactions
richlisttop 100 addresses by live balance
gapsblocks recorded without a body
halvinglive-state occupancy, expansion window, header history
economicssupply, burn, state pressure, development allocation, recorded activity

Amounts are in µNOID (1 NOID = 1 000 000 µNOID); totals that can exceed 2^53 are decimal strings. Source and documentation: github.com/gustlborg/gb-parano1d-permanode (AGPL-3.0).
